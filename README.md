# Mobile Attendance Management

An Android attendance management application built with Kotlin, Jetpack Compose, and Supabase.

The project enables teachers to manage classes and attendance sessions, while students can register their attendance using QR codes and location verification.

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Architecture:** MVVM
- **Backend Services:** Supabase
- **Database:** PostgreSQL
- **Authentication:** Supabase Auth
- **Additional Features:** QR code scanning and GPS-based location verification

## Features

- Teacher and student authentication.
- Classroom and student management.
- Attendance registration using temporary QR codes.
- Location-based attendance verification.
- Attendance history and frequency tracking.
- In-app invitations and notifications.
